# 跨平台广告政策版本回放

维护多平台健康广告政策版本并重放历史决定。

## 参与方与事实

主要参与方包括平台政策团队、联合审核中心、广告主合规人员、监管联络人员。领域资料记录以下事实：

- 不同平台对 AI 标识、专业身份和医疗承诺的执行力度不同
- 监管要求责任链可追溯而不能只看最终下架结果
- 政策会持续补充 AI 生成内容和健康广告的边界

## 业务边界

- 平台规则
- 权威来源
- 生效时间
- 优先级
- 决定重放

当前资料按以下边界组织：

- 政策来源
- 规则版本
- 平台适配
- 决定快照
- 差异解释

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/replay_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
